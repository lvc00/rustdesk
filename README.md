# RustDesk 安卓端交互改造（UU 远程风格）

把 RustDesk 官方安卓客户端的远控触屏交互，改成 UU 远程那种「手指直接操控远端」的手感。

只动 Flutter 层，不碰 Rust core。构建基线是 upstream `1.5.3`（Flutter 3.24.5），  
`librustdesk.so` 直接取自官方同版本 APK，JNI 接口完全对齐，所以手势和 UI 的改动不需要重新编译 core。

---

## 为什么改

官方安卓端在触屏远控上有几个卡点：

- **单指要「先突破阈值」**：光标需要越过约 18px 的 `kPanSlop` 才开始动，微调远端小控件时很别扭。
- **双指判定靠单一 `scale` 值**：滚动时两指间距的自然抖动会被当成缩放，画面跟着手指漂。
- **缩放一旦误触发就回不去**：`scale` 漂到 1.01 以上后，之后每次双指操作都被当成平移。
- **功能藏在菜单里**：远控过程中要翻好几层才能找到键盘、显示设置。

改造目标是三件事：**单指零门槛跟手**、**双指严格分模式互不串味**、**常用功能一屏可达**。

## 手势

| 操作         | 行为                           |
| ---------- | ---------------------------- |
| 单指滑动       | 远端光标跟随（无 slop 门槛）            |
| 单指轻点       | 左键单击                         |
| 单指长按 350ms | 右键单击（按住不动后直接松手） |
| 长按后拖动 | 拖拽（按住左键拖动，松手结束） |
| 双指上下滑      | 滚轮（24px 一格，带累积）              |
| 双指捏合 / 张开  | 以两指中心为焦点缩放画面                 |
| 双指拖动       | 平移已放大的画面（`scale > 1.12` 才生效） |
| 双指轻点       | 右键单击                         |
| 三指轻点       | 显示 / 隐藏底部工具栏                 |

### 拖拽为什么是「长按后」

拖拽和「单指滑动移动光标」共用同一根手指，所以必须有个区分动作。这里用长按：
按住不动约 350ms（`_dragArmMs`）后，手指再移动就按住左键拖动，松手才松开左键。

关键一点：长按只是**上膛**，不在那一刻就按下左键。真正的按下发生在长按后的第一次移动——
否则「长按想右键」的人会先误触发一次左键单击。所以：

- 按住不动 350ms 后直接松手 → 右键单击，全程没有左键按下过
- 按住不动 350ms 后开始移动 → 原地按住左键，跟着手指拖动，松手结束
- 350ms 之前就移动 → 只是移动光标，不进入拖拽（这样缓慢精调光标不会误拖）

原版那套「双击再按住拖」已经去掉：要多点一次、节奏偏慢，容易在拖文件时手忙脚乱。

### 双指是怎么区分的

一次手势内只允许锁定一种模式：`scroll` / `pinch` / `pan`，锁定后不再来回切换。

判定不看整段手势的累计量（那样滚动久了间距漂移会越线），而是看**最近约 3 帧的趋势**——  
用指数衰减滑窗把间距变化和两指中心位移分别累积：

```
_winSpan  = _winSpan  * 0.7 + dSpan        // 两指间距变化
_winFocal = _winFocal * 0.7 + focalMove    // 两指中心位移
```

捏合的本质是「间距在变、中心几乎不动」，滚动是「中心在走、间距基本不变」，所以判据是：

```
winSpan > 3.5
&& winSpan > winFocal * 1.2
&& spanTravel >= max(spanStart * 0.12, 30px)
&& spanStart > 60
```

四道门槛分别挡掉：噪声抖动、手指整体漂移、间距变化太小、两指靠得太近（起手间距不足时捏合不可靠）。

- 落下后 100ms 内没判成捏合，就按当前缩放状态锁成 `scroll`（未放大）或 `pan`（已放大）。
- 一旦判成 `pinch` 就不再回退，且**缩放时不平移**，避免画面和手指双重漂移。
- 进入 `pinch` 的瞬间会把起手到现在累积的缩放量一次补上（clamp 到 0.91~1.10），慢速捏合不会出现「手动了画面不动」。
- 平移只在 `scale > 1.12`（真正放大后）才允许，未放大时双指 100% 是滚轮。

## 底部工具栏

原版 `getBottomAppBar()` 那套系统风格的操作菜单，换成了 UU 远程式的浮动工具条：

- 圆角深色浮条（`0xF21F2124`，圆角 20，高 58，`SafeArea` 避让），带投影，压在画面底部。
- 六个按钮等距排列，**图标在上、文字在下**（文字 10px），一眼能认：
  | 按钮 | 行为                       |
  | -- | ------------------------ |
  | 断开 | 结束当前会话                   |
  | 键盘 | 唤起软键盘（只读会话或远端无键盘输入能力时置灰） |
  | 手势 | 打开 / 关闭手势帮助页             |
  | 显示 | 打开画质、缩放、显示设置             |
  | 聊天 | 打开文字会话                   |
  | 更多 | 打开其余动作菜单                 |
- 三指轻点可以整条切换工具栏的显隐，切换时会先收起手势帮助页，不会叠两层浮层。
- 工具栏的显示状态由 `_showBar` 控制，三指轻点通过 `uuToolbarToggleTick` 这个 `ValueNotifier<int>` 把信号传给 `RemotePage`。

## 手势帮助页

`gesture_help.dart` 里的示意图条目改成了与本改造一致的一组（原版写的是「三指上下滑=滚轮」「双指移动=画布移动」，和实际行为对不上）：

单指轻点=左键 · 单指长按=右键 · 单指滑动=移动光标 · 长按后拖动=拖拽 ·  
双指上下滑=滚轮 · 双指捏合=缩放 · 双指拖动=平移（放大后） · 三指轻点=显示/隐藏工具栏

---

## 与原版的差异

| 项     | 官方 1.5.3             | 本改造                            |
| ----- | -------------------- | ------------------------------ |
| 单指移动  | 需越过约 18px 阈值         | 立即跟手                           |
| 双指滚动  | 与缩放共用 `scale` 判定，容易串 | 独立模式，二选一                       |
| 双指缩放  | 间距轻微抖动就会触发           | 需要明确的间距变化 + 中心基本不动             |
| 放大后平移 | `scale` 一漂就跟着走       | 仅在 `scale > 1.12` 且锁 `pan` 后生效 |
| 底部工具栏 | 系统风格操作菜单             | 圆角浮条，六键直达                      |
| 手势帮助  | 原版条目                 | 与实际行为一致                        |

## 代码落点

| 文件                                             | 作用                                                             |
| ---------------------------------------------- | -------------------------------------------------------------- |
| `flutter/lib/common/widgets/raw_trackpad.dart` | 新增。`RawTrackpadLayer` 用裸 `Listener` 接管指针事件，绕开手势竞技场和 `kPanSlop` |
| `flutter/lib/common/widgets/remote_input.dart` | 接入点，在 `_RawTouchGestureDetectorRegionState.build()` 里挂上上面这层    |
| `flutter/lib/mobile/pages/remote_page.dart`    | 底部工具栏（`getBottomAppBar()`）与三指切换逻辑                              |

**一键回退**：把 `raw_trackpad.dart` 顶部的 `useRawTrackpadLayer` 改成 `false`，即恢复官方手势路径，其他文件不用动。

## 构建与安装

- 构建走 GitHub Actions：检出 upstream `1.5.3`，叠加上面四个文件，只从官方 APK 取 `librustdesk.so` + `libc++_shared.so`，产出 `arm64-v8a` 的 split APK。
- 产物发布在 Release `ux-latest`。仓库为私有，下载需登录 GitHub 账号：  
  `https://github.com/lvc00/rustdesk/releases/download/ux-latest/rustdesk-1.5.3-ux-arm64-v8a.apk`
- 安装环境：Android 8 及以上的 arm64 设备。
